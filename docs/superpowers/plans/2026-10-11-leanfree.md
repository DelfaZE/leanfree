# LeanFree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** construire LeanFree, une PWA perso (iPhone) de suivi des calories : objectif calculé chaque jour (métabolisme + pas + exercice + digestion), scan IA des repas (Gemini), code-barres (Open Food Facts), pesées.

**Architecture :** fichiers statiques sans framework ni build, servis par GitHub Pages. La logique métier est en modules ES purs (`calc.js`, `store.js`, `gemini.js`, `off.js`, `sync.js`) testés avec `node --test`. `app.js` relie le DOM à ces modules. Les données sont dans `localStorage`.

**Tech Stack :** HTML/CSS/JS (modules ES), Node ≥ 20 pour les tests (`node:test`, `node:assert`), API REST Gemini, API Open Food Facts v2, `@zxing/library@0.21.3` (copiée dans `vendor/`).

**Spec :** `docs/superpowers/specs/2026-10-11-leanfree-design.md`

```js
// Fonctions pures : aucun accès au DOM ni au stockage.

export const EXERCISES = [
  { key: 'muscu', label: 'Musculation (classique)', met: 3.5 },
  { key: 'muscu-intense', label: 'Musculation intense', met: 5.0 },
  { key: 'velo', label: 'Vélo / elliptique modéré', met: 7.0 },
  { key: 'course', label: 'Course ~10 km/h', met: 9.8 },
  { key: 'natation', label: 'Natation', met: 5.8 },
  { key: 'hiit', label: 'Cours collectif / HIIT', met: 8.0 },
];

export const RATES = [-1, -0.75, -0.5, -0.25, 0, 0.25];

export function ymd(d = new Date()) {
  const p = n => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}

export function addDays(dateStr, n) {
  const [y, m, d] = dateStr.split('-').map(Number);
  return ymd(new Date(y, m - 1, d + n));
}

export function latest(weights) {
  if (!weights.length) return null;
  const sorted = [...weights].sort((a, b) => a.date.localeCompare(b.date));
  const withFat = sorted.filter(w => w.fatPct != null).at(-1);
  return { kg: sorted.at(-1).kg, fatPct: withFat ? withFat.fatPct : null };
}

export function bmr(profile, kg, fatPct) {
  if (fatPct != null) return 370 + 21.6 * kg * (1 - fatPct / 100);
  const base = 10 * kg + 6.25 * profile.heightCm - 5 * profile.age;
  return profile.sex === 'F' ? base - 161 : base + 5;
}

export function stepsKcal(steps, heightCm, kg) {
  const km = (steps * 0.415 * heightCm) / 100 / 1000;
  return km * kg * 0.5;
}

export function exerciseKcal(met, minutes, kg) {
  return (Math.max(0, met - 1) * kg * minutes) / 60;
}
```

```js
export function dailyTarget({ bmr, steps, exercise, rate, sex }) {
  // X = dépense − déficit, avec dépense = bmr + pas + exo + 0,1·X (digestion) → X = (…) / 0,9
  const raw = (bmr + steps + exercise + (rate * 7700) / 7) / 0.9;
  const floor = sex === 'F' ? 1200 : 1500;
  return raw < floor ? { kcal: floor, floored: true } : { kcal: raw, floored: false };
}

export function macroTargets(kcal, kg, fatPct) {
  const protein = fatPct != null ? 2.2 * kg * (1 - fatPct / 100) : 1.8 * kg;
  const fat = (kcal * 0.25) / 9;
  const carbs = Math.max(0, (kcal - protein * 4 - fat * 9) / 4);
  return { protein, fat, carbs };
}

export function weeksToGoal(kg, goalKg, rate) {
  const diff = goalKg - kg; // négatif = perte
  if (diff === 0) return 0;
  if (rate === 0 || Math.sign(diff) !== Math.sign(rate)) return null;
  return diff / rate;
}

export function scaleItem(base, grams) {
  if (!(base.grams > 0)) return { ...base, grams };
  const f = grams / base.grams;
  return { grams, kcal: base.kcal * f, protein: base.protein * f, carbs: base.carbs * f, fat: base.fat * f };
}

export function totals(list) {
  return list.reduce(
    (t, x) => ({
      kcal: t.kcal + (x.kcal || 0),
      protein: t.protein + (x.protein || 0),
      carbs: t.carbs + (x.carbs || 0),
      fat: t.fat + (x.fat || 0),
    }),
    { kcal: 0, protein: 0, carbs: 0, fat: 0 },
  );
}

export function avg7(weights) {
  const sorted = [...weights].sort((a, b) => a.date.localeCompare(b.date));
  return sorted.map(w => {
    const from = addDays(w.date, -6);
    const win = sorted.filter(x => x.date >= from && x.date <= w.date);
    return { date: w.date, kg: win.reduce((s, x) => s + x.kg, 0) / win.length };
  });
}

export function parseSteps(text) {
  const s = String(text ?? '').replace(/[\s  ]/g, '').replace(',', '.');
  if (!/^\d+(\.\d+)?$/.test(s)) return null;
  const n = Math.round(Number(s));
  return n <= 100000 ? n : null;
}

export function dayPlan(profile, weights, day) {
  const w = latest(weights);
  const b = bmr(profile, w.kg, w.fatPct);
  const steps = stepsKcal(day.steps || 0, profile.heightCm, w.kg);
  const exercise = totals(day.exercises).kcal;
  const target = dailyTarget({ bmr: b, steps, exercise, rate: profile.rateKgPerWeek, sex: profile.sex });
  const eaten = totals(day.meals);
  return {
    bmr: b,
    steps,
    exercise,
    digestion: eaten.kcal * 0.1,
    target,
    eaten,
    macros: macroTargets(target.kcal, w.kg, w.fatPct),
  };
}
```

```js
const KEY = 'leanfree';
export const DEFAULT_MODEL = 'gemini-flash-latest';

export function emptyState() {
  return { profile: null, weights: [], days: {}, favorites: [], settings: { apiKey: '', model: DEFAULT_MODEL, gistId: '' } };
}

export function load(storage = globalThis.localStorage) {
  try {
    return { ...emptyState(), ...JSON.parse(storage.getItem(KEY)) };
  } catch {
    return emptyState();
  }
}

export function save(state, storage = globalThis.localStorage) {
  storage.setItem(KEY, JSON.stringify(state));
}

export function day(state, date) {
  return (state.days[date] ??= { steps: 0, exercises: [], meals: [] });
}

export function upsertWeight(state, entry) {
  state.weights = state.weights.filter(w => w.date !== entry.date);
  state.weights.push(entry);
  state.weights.sort((a, b) => a.date.localeCompare(b.date));
}

export function exportJson(state) {
  const { apiKey, ...settings } = state.settings;
  return JSON.stringify({ ...state, settings }, null, 2);
}

export function importJson(text, current) {
  const data = JSON.parse(text);
  if (!data || typeof data !== 'object' || !data.profile || !Array.isArray(data.weights)) {
    throw new Error('Fichier invalide');
  }
  return {
    ...emptyState(),
    ...data,
    settings: {
      apiKey: current.settings.apiKey,
      model: data.settings?.model || current.settings.model,
      gistId: data.settings?.gistId ?? current.settings.gistId,
    },
  };
}
```

```js
const NUM = { type: 'NUMBER' };

export const SCHEMA = {
  type: 'OBJECT',
  properties: {
    dish: { type: 'STRING' },
    confidence: { type: 'STRING', enum: ['low', 'medium', 'high'] },
    items: {
      type: 'ARRAY',
      items: {
        type: 'OBJECT',
        properties: { name: { type: 'STRING' }, grams: NUM, kcal: NUM, protein: NUM, carbs: NUM, fat: NUM },
        required: ['name', 'grams', 'kcal', 'protein', 'carbs', 'fat'],
      },
    },
  },
  required: ['dish', 'confidence', 'items'],
};

export function buildPrompt(description) {
  return [
    'Tu es nutritionniste. Analyse la photo de ce repas.',
    'Estime la portion VISIBLE sur la photo, pas une portion standard.',
    'Détaille chaque aliment séparément : nom en français, poids en grammes, kcal, protéines, glucides et lipides en grammes.',
    'Compte les huiles, beurres et sauces probables comme des aliments à part.',
    "Si aucun aliment n'est visible, renvoie une liste items vide.",
    description ? `Description donnée par l'utilisateur : ${description}` : '',
  ].filter(Boolean).join('\n');
}

export function buildBody(base64, description) {
  return {
    contents: [{ parts: [
      { inlineData: { mimeType: 'image/jpeg', data: base64 } },
      { text: buildPrompt(description) },
    ] }],
    generationConfig: { responseMimeType: 'application/json', responseSchema: SCHEMA },
  };
}

export function parseResponse(json) {
  let data;
  try {
    data = JSON.parse(json.candidates[0].content.parts[0].text);
  } catch {
    throw new Error('Réponse illisible, réessaie.');
  }
  if (!Array.isArray(data.items) || data.items.length === 0) {
    throw new Error('Aucun aliment détecté. Essaie un autre angle.');
  }
  return data;
}

export function httpError(status, message = '') {
  if (status === 429) return 'Quota du jour atteint. Saisis le repas à la main ou réessaie demain.';
  if (status === 404) return 'Modèle introuvable : change-le dans les réglages.';
  if (status === 401 || status === 403 || /api key/i.test(message)) {
    return 'Clé refusée : vérifie la clé et ses restrictions.';
  }
  return `Erreur Gemini (${status}) : ${message}`;
}

export async function analyze({ apiKey, model, base64, description }, fetchFn = fetch) {
  let res;
  try {
    res = await fetchFn(
      `https://generativelanguage.googleapis.com/v1beta/models/${encodeURIComponent(model)}:generateContent`,
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', 'x-goog-api-key': apiKey },
        body: JSON.stringify(buildBody(base64, description)),
      },
    );
  } catch {
    throw new Error("Hors ligne : le scan n'est pas disponible.");
  }
  const json = await res.json().catch(() => ({}));
  if (!res.ok) throw new Error(httpError(res.status, json.error?.message));
  return parseResponse(json);
}
```

```js
export function productToFood(json, code) {
  const p = json?.product;
  if (json?.status !== 1 || !p) return null;
  const n = p.nutriments || {};

    grams: 100,
    kcal,
    protein: n.proteins_100g ?? 0,
    carbs: n.carbohydrates_100g ?? 0,

}
```

```js
import { parseSteps } from './calc.js';

export function gistIdFrom(text) {
  return String(text ?? '').trim().replace(/\/+$/, '').split('/').pop();
}

export function parseGist(json) {
  const raw = json?.files?.['steps.json']?.content;
  if (raw == null) throw new Error('steps.json absent du gist');
  const days = {};
  for (const [date, value] of Object.entries(JSON.parse(raw))) {
    const n = parseSteps(value);
    if (/^\d{4}-\d{2}-\d{2}$/.test(date) && n != null) days[date] = n;
  }
  return { days, updatedAt: json.updated_at };
}

export async function fetchSteps(gistId, fetchFn = fetch) {
  const res = await fetchFn(`https://api.github.com/gists/${encodeURIComponent(gistId)}`, { cache: 'no-store' });
  if (!res.ok) throw new Error(`Gist introuvable (${res.status})`);
  return parseGist(await res.json());
}
```

- [ ] **Step 1 : Créer `sw.js`**

```js
// Incrémenter VERSION à chaque déploiement pour que l'iPhone récupère la nouvelle version.
const VERSION = 1;
const CACHE = `leanfree-v${VERSION}`;
const FILES = ['./', 'index.html', 'style.css', 'app.js', 'calc.js', 'store.js', 'gemini.js', 'off.js', 'sync.js', 'vendor/zxing.min.js', 'manifest.json'];

self.oninstall = e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(FILES)).then(() => self.skipWaiting()));
};

self.onactivate = e => {
  e.waitUntil(
    caches.keys()
      .then(keys => Promise.all(keys.filter(k => k !== CACHE).map(k => caches.delete(k))))
      .then(() => self.clients.claim()),
  );
};

self.onfetch = e => {
  if (e.request.method !== 'GET' || new URL(e.request.url).origin !== location.origin) return;
  e.respondWith(caches.match(e.request).then(r => r || fetch(e.request)));
};
```

````markdown
## Synchro des pas (Santé → LeanFree)

Une web app n'a pas accès à Santé : un raccourci iOS dépose tes pas dans un gist GitHub
secret, et LeanFree les relit à chaque ouverture.

1. **Gist** : https://gist.github.com → nom de fichier `steps.json`, contenu `{}` →
   **Create secret gist**. Copier son URL : l'identifiant est la dernière partie.
2. **Token** : GitHub → Settings → Developer settings → Personal access tokens →
   **Tokens (classic)** → Generate new token (classic) → cocher **uniquement `gist`** →
   copier le token (`ghp_…`). Il ne sert qu'au raccourci.
3. **Raccourci « Synchro pas LeanFree »** (app Raccourcis → **+**) :
   1. **Date** (actuelle) → **Formater la date**, format personnalisé `yyyy-MM-dd` →
      **Définir la variable** `Aujourdhui`.
   2. **Ajuster la date** : Date actuelle moins 1 jour → **Formater la date** `yyyy-MM-dd` →
      variable `Hier`.
   3. **Rechercher des échantillons de santé** : Type = Pas, Date de début = aujourd'hui →
      **Calculer les statistiques** : Somme → variable `PasAujourdhui`.
   4. Pareil pour hier (filtre « Date de début est hier », ou « est entre » minuit d'hier et
      minuit d'aujourd'hui) → variable `PasHier`.
   5. **Texte** : `{"[Aujourdhui]": "[PasAujourdhui]", "[Hier]": "[PasHier]"}`, en insérant
      les variables à la place des crochets. Garde les guillemets autour des nombres :
      LeanFree accepte « 8 432 » comme « 8432 ».
   6. **Obtenir le contenu de l'URL** : `https://api.github.com/gists/<ID_DU_GIST>`,
      méthode **PATCH**, en-têtes `Authorization` = `Bearer <TOKEN>` et
      `Accept` = `application/vnd.github+json`, corps **JSON** : `files` (dictionnaire) →
      `steps.json` (dictionnaire) → `content` (texte) = le Texte de l'étape 5.
4. **Automatisations** : Raccourcis → Automatisation → **+** → Heure de la journée → 12:00,
   Quotidien → **Exécuter immédiatement** → « Synchro pas LeanFree ». Recommencer pour
   18:00, 21:00 et 23:30.
5. **LeanFree** → Réglages → Synchro des pas → coller l'URL du gist →
   **Enregistrer et synchroniser**.

Les libellés exacts peuvent varier légèrement selon la version d'iOS. En secours : le
champ Pas reste modifiable, et le bouton **Coller** lit un nombre copié.

Sécurité : le gist secret est lisible par quiconque connaît son adresse (il ne contient
que des nombres de pas). Le token peut modifier tes gists : en cas de fuite, le révoquer
dans GitHub et en mettre un nouveau dans le raccourci.
````
